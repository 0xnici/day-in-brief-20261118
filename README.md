One page, one day: Wednesday 18 November 2026 as a newspaper front page. The date itself is the headline, and six panels below it carry the day in brief — the US strike on an Iranian missile site on Qeshm Island and Tehran's drone answer, the Kerch Bridge hit for a second straight day, Xi and Putin meeting in Shenzhen, Mary Peltola's Alaska win taking the Democrats to 56 Senate seats, Ebola cases more than doubling in DR Congo, and Nvidia's record revenue — with an "also today" strip along the bottom for the cyclone in the Cook Islands, the Papua New Guinea quake, the Siberian plane crash and the new Knesset speaker. All of it is that day's wire reporting, set in large serif type that stays legible at thumbnail size. `tools/render.py` did the typesetting; `main.py` writes the finished page, byte for byte, to the output directory and verifies the copy against the original before it reports success.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
