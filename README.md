Wednesday 18 November 2026 on one page: a newspaper front page that sums up the day's world news in a single image. The date is the headline; six panels carry the day's stories — the US strike on an Iranian missile site on Qeshm Island and Tehran's drone answer, the Kerch Bridge hit for a second day, Xi and Putin meeting in Shenzhen, Mary Peltola's Alaska win taking Democrats to 56 Senate seats, Ebola cases more than doubling in DR Congo, and Nvidia's record revenue — plus an "also today" strip for the cyclone, the Papua New Guinea quake, the Siberian plane crash and the new Knesset speaker. Every story and figure is that day's wire reporting, set in large serif type that stays readable at thumbnail size. The page was typeset by `tools/render.py`; `main.py` writes it, byte for byte, to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
